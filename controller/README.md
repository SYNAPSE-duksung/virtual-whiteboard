# controller — 메인 제어 루프

`controller/main.py`의 `WhiteboardSession`이 트래킹·펜 판정·캔버스·기록·캘리브레이션을
모두 관리하는 세션 객체다. `process_frame(bgr_frame) -> annotated_frame`이 프레임 단위
단일 진입점이라, OpenCV 데모(`controller.main.main()`)와 PyQt 앱(`ui/app.py`)이 완전히
동일한 파이프라인을 공유한다.

## 실행 방법

```bash
python -m controller.main
```

옵션:

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--camera N` | `0` | 카메라 장치 인덱스 |
| `--mirror` | 꺼짐 | 좌우 반전(셀피 구도). 기본은 반전 없음 — 책상을 내려다보는 구도 전제 |
| `--calibration PATH` | `output/calibration.json` | 4점 캘리브레이션 저장/로드 경로 |
| `--plane-size W H` | `297 210` (A4 가로) | 캘리브레이션할 사각형의 **실제 물리 크기(mm)**. 3D 접촉 판정에 필수 |
| `--intrinsics PATH` | `output/camera_intrinsics.json` | 카메라 내부 파라미터. 없으면 화각 60° 가정으로 근사 |
| `--no-3d` | 꺼짐 | 3D 접촉 판정을 끄고 기존 `pen_ratio` 휴리스틱만 사용 |
| `--debug-3d` | 꺼짐 | 3D 디버그 오버레이를 켠 채로 시작 (실행 중 `D`로 토글) |

예:

```bash
python -m controller.main --camera 1 --mirror
python -m controller.main --calibration output/my_desk.json
```

최초 실행 시 `output/calibration.json`이 없으면, 카메라 창이 뜨자마자 **캘리브레이션이
자동으로 시작**된다 (아래 "3D 접촉 판정" 참고). 4점을 지정해야 일반 조작으로
넘어간다.

## 펜 판정 모드 (`M` 키로 전환)

- **AUTO(자동)**: `core.PenTracker`가 손끝의 **3D 높이**(가능할 때) 또는 `pen_ratio`로
  pen up/down을 판정하고,
  손을 펴면(open hand) 캔버스를 지운다. 그 위에 `controller.state_machine.PenStateMachine`이
  디바운싱·짧은 트래킹 손실 시 획 유지·지우기 확정을 담당해 순간 오판이 그대로 렌더링에
  반영되지 않도록 안정화한다.
- **MANUAL(수동)**: 기존 방식. `SPACE`로 pen up/down을 토글하고 `C`로 지운다 (자동 판정
  무시 — 캘리브레이션 게이팅도 이 모드에는 적용되지 않는다).

## 3D 접촉 판정 (진짜 높이 기반)

**손끝이 책상 평면에서 몇 mm 떠 있는지를 실제로 복원해** 그 값으로 pen up/down을 판정한다.
`pen_ratio`(손가락이 얼마나 굽었는가)라는 2D 대리 신호를 대체한다.

**원리** (`core/contact3d.py`):
1. 4점 캘리브레이션 코너 + **평면의 실제 물리 크기(mm)** + 카메라 intrinsics → `solvePnP`로
   책상 평면의 3D 자세
2. MediaPipe **world landmarks**(손 중심 원점, 미터 단위 metric 3D 손 모델) + 같은 손의
   이미지 좌표 21쌍 → `solvePnP`로 손의 3D 자세. world landmarks가 metric이라 단일 RGB로도
   스케일 모호성이 풀린다 — 이게 핵심이다.
3. 손끝을 평면 좌표로 옮기면 z성분이 곧 **높이(mm)**

**동작 조건**: ① 캘리브레이션에 `plane_size_mm`이 있고 ② 카메라 intrinsics가 있을 때
자동으로 켜진다. 하나라도 없거나 프레임 단위로 자세 추정이 실패하면 **조용히 `pen_ratio`로
폴백**한다 (`PenFrame.contact_source`가 `"3d"`/`"ratio"`로 알려준다). 화면 배지에 `3D`/`2D`,
그리고 3D 판정 중에는 복원 높이가 `H +12.3mm`처럼 표시된다.

**평면 범위 게이팅**은 두 방식 모두에 적용된다 — 손끝이 사각형 밖이면 판정과 무관하게 pen up.

> ⚠️ **정확도와 영점 보정**: 복원 높이는 MediaPipe world landmarks의 손 모델 정확도와
> intrinsics 가정에 **비례해서** 치우친다. 합성 검증 결과 손 모델 스케일이 10% 틀리면 높이가
> **43mm** 틀어지고, 화각 가정이 20% 틀리면 8mm 틀어진다. 그래서 **영점 보정이 필수**다 —
> 실제로 표면을 짚었을 때의 측정값을 0으로 맞추면 이 계통 오차가 거의 전부 상쇄된다
> (검증: 손 모델 10% 오차 → 보정 후 5mm 지점에서 0.5mm 오차). 영점 보정은 아래 `T` 키가
> 자동으로 해준다.
>
> 남는 것은 **프레임 간 랜덤 노이즈**이고, 그 크기는 MediaPipe가 실제로 얼마나 흔들리는지에
> 달려 있어 합성으로는 알 수 없다. `python -m tools.validate_contact3d`로 실측해
> 분리도 d'를 확인할 것 — d' ≥ 3이면 안정적, 1.5 미만이면 이 신호로는 어렵다.

**평면 실제 크기**: 기본값은 A4 가로(297×210mm)다. 책상에 A4를 놓고 그 네 모서리를
캘리브레이션하면 자를 대지 않고도 정확한 값을 쓸 수 있다. 다른 영역을 쓰려면
`--plane-size 가로mm 세로mm`로 지정한다. `--no-3d`로 3D를 끄고 기존 방식만 쓸 수도 있다.

**카메라 intrinsics**: `output/camera_intrinsics.json`이 있으면 쓰고, 없으면 화각 60° 가정으로
근사한다(근사여도 영점 보정이 대부분 흡수). 정확히 재려면
`python -m tools.calibrate_camera`로 체스보드 캘리브레이션을 한다.

**라이프사이클**:

- **세션 시작 시 1회**: `output/calibration.json`이 있으면 자동 로드. 없으면(최초 실행)
  데모 루프가 시작 직후 캘리브레이션을 강제한다.
- **재캘리브레이션**: `K`를 누르면 언제든 다시 시작할 수 있다. `Enter`/`S`로 확정하기
  전까지 기존 캘리브레이션은 그대로 유효하므로, 재시도하다 실패해도 안전하다.
- 화면에 캘리브레이션한 평면 외곽선을 항상 얇게 표시하고(`CAL:OK`/`CAL:NONE` 배지 포함),
  손이 평면 밖일 때 `OUT OF PLANE` 배지를 띄워 게이팅이 실제로 작동 중인지 눈으로
  확인할 수 있다.

**4점을 손가락으로 찍기**: 캘리브레이션 중에도 손끝 추적이 계속 돌아 화면에 커서(원)로
표시된다. 마우스로 직접 클릭하는 대신, **손끝을 원하는 모서리 위에 놓고 `SPACE`를
누르면 그 위치에 점이 찍힌다** — 마우스와 섞어 써도 된다(예: 3점은 손끝, 1점은 마우스).
손이 검출되지 않으면 `SPACE`는 무시되고 클릭만 동작한다.

## 접촉 캘리브레이션 (`T` 키) — 3D 영점 + pen_ratio 임계값

4점 캘리브레이션이 "어디"(필기 영역의 XY 범위)를 정한다면, 이건 "언제"(접촉 여부)를
이 사람·이 카메라 각도에 맞게 잡는 기능이다. 한 번 실행하면 **두 신호를 동시에** 보정한다:

- **3D 영점**: touch 단계 높이의 중앙값을 영점으로 삼아 계통 오차를 상쇄하고, 접촉 문턱(mm)을
  자동 계산한다. **3D 판정을 쓰려면 이 보정이 사실상 필수다.**
- **pen_ratio 임계값**: 3D가 실패한 프레임의 폴백 신호이므로 함께 갱신한다.

두 보정은 **독립적**이다 — `pen_ratio`가 hover/touch를 구분하지 못해도(3D로 넘어온 이유가
바로 그것이므로) 3D 영점 보정은 정상적으로 성공한다. 반대도 마찬가지다.

**진행 방식** (`T`를 누르면 2단계가 자동으로 이어진다, 각 단계 기본 2.5초):

1. **hover 단계**: 손가락을 화면 위에 띄운 채(책상에 닿지 않게) 가만히 있는다.
2. **touch 단계**: 책상에 손가락을 대고 누른 상태로 유지한다.

각 단계에서 모은 표본의 중앙값을 비교해, 둘을 가장 잘 가르는 지점 근처에 문턱을 계산해
즉시 적용한다. 결과는 **파일로 저장되지 않으므로**(4점 캘리브레이션과 다름) 실행할 때마다
`T`를 다시 눌러야 한다.

> ⚠️ **자유롭게 "+"나 "X"를 그리며 캘리브레이션하는 방식은 쓰지 않는다.** 자유 드로잉은
> 중간에 살짝 손가락이 뜨는 순간이 섞이기 쉬워, touch 표본에 실제로는 "안 눌린" 값이
> 섞여 추정이 나빠질 위험이 있다. 대신 "누른 채 정지 유지"를 요구해 표본을 깨끗하게
> 만든다. 표본이 15개 미만이거나(추적 실패), 두 단계가 실제로 구분되지 않으면(예: touch
> 단계에서 실제로 누르지 않음) 그 신호의 보정은 거부되고 기존 값이 유지된다 — 화면
> 메시지에 이유가 뜬다. 자세한 통계 로직은 `core/touch_calibration.py` docstring 참고.

4점 캘리브레이션(`K`)과 접촉 캘리브레이션(`T`)은 동시에 진행할 수 없다 — 하나가
진행 중일 때 다른 하나를 누르면 무시된다.

## 3D 디버그 오버레이 (`D` 키 / PyQt "3D 디버그" 버튼)

"지금 손끝이 평면에서 얼마나 떨어져 있는가"와 그 판정 근거를 영상 위에 겹쳐 본다.
기본은 꺼져 있고, 꺼져 있으면 계산 자체를 건너뛴다(프레임당 추가 투영 비용 없음).

화면에 표시되는 것:

| 요소 | 의미 |
|------|------|
| **수선 벡터** | 손끝 → 평면에 내린 수선의 발을 잇는 선. 이게 평면에 **직교하는** 벡터이며 그 길이가 곧 높이다. 접촉 중이면 초록, 아니면 주황 |
| **수선의 발(십자)** | 손끝을 평면 위로 정사영한 위치 |
| **높이 눈금** | 수선을 따라 찍은 0/10/20/30/50mm 눈금 (**영점 보정 후** 유효 높이 기준) |
| **`down` / `up` 선** | 실제 판정에 쓰이는 접촉 문턱. 두 선 사이가 히스테리시스 구간이다 |
| **왼쪽 높이 게이지** | 현재 높이를 −20~80mm 막대로 표시. 문턱 위치도 함께 그린다 |
| **우상단 수치 패널** | 유효 높이 / 원시 높이 / 영점 / 문턱 / 평면 XY / 손 자세 재투영 오차 / 판정 신호 |

**왼쪽 게이지가 따로 있는 이유**: 카메라가 책상을 거의 수직으로 내려다보면 평면의 법선이
시선과 거의 나란해져, 화면에 투영된 수선이 몇 픽셀로 찌부러져 눈으로 읽을 수 없다.
게이지는 3D를 투영하지 않고 높이 **값**만 막대로 그리므로 그 구도에서도 항상 읽힌다.

**수선의 발과 `0mm` 눈금이 떨어져 보이는 것은 정상이다** — 발은 기하학적 평면(원시 높이 0)이고
눈금은 영점 보정 후 기준이라, 둘의 간격이 곧 영점 보정량(`zero offs`)이다. 영점 보정 전
(`T`를 누르기 전)에는 이 간격이 수십 mm까지 벌어질 수 있다.

디버그를 켰는데 오버레이가 안 보이면 그 이유가 화면 상단에 뜬다:
- `3D DEBUG: OFF - need 4-pt calibration + plane size + intrinsics` → 3D 판정 자체가 비활성 (`K`로 4점 지정)
- `3D DEBUG: hand pose failed this frame` → 이번 프레임 손 자세 추정 실패, `pen_ratio`로 폴백 중

> 오버레이 문구가 모두 영문인 것은 의도적이다 — OpenCV의 Hershey 폰트에는 한글 글리프가
> 없어 한글을 넣으면 `?????`로 깨진다. PyQt 쪽 상태 라벨은 한글로 표시된다.

## 키 조작

**일반 모드**

| 키 | 동작 |
|---|---|
| `M` | AUTO ↔ MANUAL 모드 전환 |
| `SPACE` | (MANUAL 모드) pen up/down 토글 |
| `K` | 4점 캘리브레이션 (재)시작 |
| `T` | 접촉 캘리브레이션 (재)시작 — 3D 영점 + pen_ratio 임계값 |
| `D` | 3D 디버그 오버레이 on/off (평면 수선 벡터 · 높이 게이지 · 수치 패널) |
| `R` | 좌표 CSV 기록 on/off (`output/coords_*.csv`) |
| `C` | 캔버스 지우기 |
| `S` | 캔버스를 PNG로 저장 (`captures/canvas_<timestamp>.png`) |
| `Q` | 종료 |

**4점 캘리브레이션 모드** (순서는 항상 TL→TR→BR→BL, 좌상단부터 시계방향)

| 입력 | 동작 |
|---|---|
| 좌클릭 | 클릭 위치에 점 추가 (최대 4개) |
| `SPACE` | **현재 손끝 위치**에 점 추가 (손이 검출된 경우만) |
| `Z` | 마지막 점 취소 |
| `X` | 전체 리셋 |
| `Enter` / `S` | 4점 확정 → 적용 + `output/calibration.json` 저장 |
| `Esc` | 캘리브레이션 취소 (기존 캘리브레이션이 없으면 — 즉 세션 최초 실행이면 — 취소 불가, 4점을 마저 지정해야 한다) |

퇴화한 4점(점이 서로 너무 가깝거나, 순서가 꼬여 자기교차하는 경우)은 `Enter`/`S`로 확정
시 오류 메시지와 함께 거부되고 캘리브레이션 모드가 유지된다 — 다시 점을 찍거나 `X`로
리셋하면 된다.

**접촉 캘리브레이션 모드**

| 입력 | 동작 |
|---|---|
| (없음, 자동 진행) | 화면 안내에 따라 hover→touch 순으로 자세를 유지하면 자동으로 완료된다 |
| `Esc` | 취소 (기존 임계값 유지) |

## 산출물

| 경로 | 내용 |
|---|---|
| `output/calibration.json` | 4점 캘리브레이션 (`core.geometry.PerspectiveCalibration`) |
| `output/coords_*.csv` | 좌표 기록 (`R` 키, `core.recorder.CoordRecorder`) |
| `captures/canvas_*.png` | 저장한 캔버스 (`S` 키) |

접촉 캘리브레이션 결과(3D 영점·문턱, pen_ratio 임계값)는 파일로 저장되지 않는다(세션
메모리에만 적용) — 매 실행 후 `T`로 다시 보정한다. 카메라 intrinsics는
`output/camera_intrinsics.json`에 저장되어 재사용된다.

## 관련 모듈

- `core.PenTracker` — 손끝 추적 + pen_ratio 판정 + 평면 게이팅 + 임계값 런타임 교체 (`core/pen_tracker.py`)
- `controller.state_machine.PenStateMachine` — AUTO 모드 안정화(디바운싱·손실 홀드·지우기 확정)
- `core.geometry` — `PerspectiveCalibration`(변환 행렬), `CalibrationPicker`(4점 선택 상태머신)
- `core.contact3d` — **3D 접촉 판정**: 평면/손 자세 `solvePnP`, 높이(mm) 복원, 영점 보정
- `core.camera` — 카메라 intrinsics (`CameraIntrinsics`, 화각 근사 / 체스보드 로드)
- `core.touch_calibration` — hover/touch 표본으로부터 히스테리시스 임계값 추정 (`estimate_thresholds`)
- `tools/calibrate.py` — 4점 캘리브레이션 전용 독립 도구 (같은 `CalibrationPicker`를 재사용, 마우스 전용)
- `tools/calibrate_camera.py` — 체스보드 카메라 캘리브레이션 (정식 intrinsics 생성)
- `tools/validate_contact3d.py` — **3D 접촉 신호 실측 검증** (노이즈·분리도 d' 측정, pen_ratio와 비교)
